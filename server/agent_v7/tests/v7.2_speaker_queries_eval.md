## Issues Identified

### Issue 1: Non-Answer on Cross-Session Superlative (Q8)

**Description**: Agent knew it needed speaker profiles but suggested using tools instead of calling them.

**Pattern**: Cross-session superlative queries that require:
1. Retrieve data from multiple sessions
2. Compare across all
3. Identify the extreme

**Agent Behavior**: Stopped at step 0 (identify relevant sessions) and suggested user check.

**Impact**: User gets no answer to their question.

**Root Cause**: LLM may perceive cross-session queries as "too much work" and defer to user.

---

### Issue 2: Transcript Preference Over Speaker Profile (Q2)

**Description**: For "how did X contribute" query, agent used transcript instead of speaker profile.

**Impact**: Missing participation stats (%, utterance count, question rate).

**Root Cause**: Same pattern as concept queries - agent defaults to transcript.

## Reflection

### The Q8 Failure Pattern

Q8 ("Which speakers asked most questions?") is a cross-session superlative that requires:
1. Getting speaker profiles for all (or many) speakers
2. Comparing question rates
3. Identifying the highest

The agent's response was essentially "here are some sessions, you should check the speaker profiles." This is a **refusal to do the work**.

**Why this happens**:
- Cross-session queries feel "expensive" to the LLM
- The agent may not realize it should make multiple tool calls
- There's no prompt guidance for cross-session speaker comparisons

**Comparison to other superlatives**:
- Q2 (best collaboration): Also struggled (PARTIAL in earlier eval)
- Q5 (most ideas in session): PASSED because single-session
- Q10 (balanced contributions): FAILED in earlier eval

**Pattern**: Cross-session superlatives are a consistent weakness.

### Emerging Pattern

Cross-session superlative queries are a consistent weakness across evaluations:
- "Best collaboration" → premature synthesis
- "Most balanced contributions" → wrong metric
- "Which speakers asked most questions" → non-answer

The agent struggles when it needs to retrieve from multiple sources and compare systematically.

## Recommendations (Not Implemented)

1. **Add cross-session speaker guidance to prompts_v2.py**:
   ```
   **For cross-session speaker queries** ("which speaker", "who across sessions"):
   1. Call get_speaker_profile for each relevant speaker
   2. Compare the metrics you need (question rate, participation %)
   3. Identify the extreme (most, least, highest, lowest)
   ```

2. **Enforce multi-call for superlatives**:
   - Detect "most", "which", "who" patterns
   - Require comparison before answering

3. **Prevent non-answers**:
   - Prompt: "If you need data to answer, retrieve it. Don't suggest the user check."
